# renanleonel/ui

Personal design system: a [shadcn](https://ui.shadcn.com) registry on [Base UI](https://base-ui.com), themeable with any [tweakcn](https://tweakcn.com) theme. Accessible by default (axe WCAG 2.2 AA audited on every page), responsive down to 320px, light and dark.

Docs and live previews: [ui.renanleonel.com](https://ui.renanleonel.com).

## Install

```bash
R=https://ui.renanleonel.com/r

npx shadcn init $R/base.json                            # new project: tokens, utils, every component
npx shadcn add $R/theme-caffeine.json                   # a theme from this registry (neutral, caffeine, amethyst-haze)
npx shadcn add https://tweakcn.com/r/themes/<id>.json   # ...or any tweakcn theme
npx shadcn add $R/button.json                           # one component in an existing project
npx shadcn add $R/app-shell.json $R/data-table.json     # blocks
```

Or register the namespace once in the project's `components.json` and add items by name:

```json
"registries": {
  "@renanleonel": "https://ui.renanleonel.com/r/{name}.json"
}
```

```bash
npx shadcn add @renanleonel/button @renanleonel/app-shell @renanleonel/theme-caffeine
```

### For AI agents

With the `@renanleonel` namespace registered (above), the shadcn MCP server can search and install from this registry. Run `npx shadcn@latest mcp init --client claude` (or `cursor`, `vscode`, `codex`, `opencode`), or write the config yourself:

```json
// Claude Code: .mcp.json    Cursor: .cursor/mcp.json
{ "mcpServers": { "shadcn": { "command": "npx", "args": ["shadcn@latest", "mcp"] } } }
```

The server reads the `registries` in the project's `components.json`. Agents without MCP can read [`llms.txt`](public/llms.txt) (index) or [`llms-full.txt`](public/llms-full.txt) (notes, exports, changelog), generated by `registry:build`.

#### Design-system MCP

A second, read-only MCP server ships with the docs site at `/mcp` (Streamable HTTP, no auth). Where the shadcn MCP installs items, this one explains them: usage stories (`get_examples`), design rules (`get_rules`), `--ds-*` tokens (`get_tokens`), full item source and dependencies (`get_item`), plus `list_items`, `search` and `get_changelog`. It reads the committed registry output, so new items appear without any list to maintain.

```bash
claude mcp add --transport http renanleonel-ui https://ui.renanleonel.com/mcp
```

```json
// Cursor: .cursor/mcp.json
{ "mcpServers": { "renanleonel-ui": { "url": "https://ui.renanleonel.com/mcp" } } }
```

Check a running instance with `pnpm mcp:smoke [url]` (default `http://localhost:3000/mcp`).

## Theming in layers

1. **Theme** (shadcn contract): `--primary`, `--radius`, `--font-sans`, `--shadow-*`… anything tweakcn exports.
2. **Tokens** (`registry/tokens.mjs`): what themes don't cover. Defaults derive from layer 1, so override only what you need:

   ```css
   :root { --ds-radius-control: 9999px; --ds-control-h: 2.5rem; } /* pill buttons, comfortable density */
   ```

3. **Components** read only layers 1 and 2.

Build a theme visually at `/themes/builder` (live preview, contrast check, tweakcn JSON and CSS export, shareable URL).

### Design tokens for Figma

`pnpm tokens:export` (also run by `registry:build`) writes `public/tokens/<theme>.tokens.json` in the [W3C Design Tokens Format](https://www.designtokens.org/tr/2025.10/format/): token sets `core`, `light` and `dark`, with `--ds-*` tokens referencing theme tokens (`{color.ring}`). Colors are sRGB hex; the authored oklch value stays in `$extensions`.

- **Tokens Studio**: Settings > Token Format > W3C DTCG, then import the JSON. The `$themes` entries select `core` plus `light` or `dark`.
- **Figma Variables**: import through Tokens Studio's Variables export, or any DTCG-aware importer; map the `light` and `dark` sets to two modes.

## Develop

```bash
pnpm install
pnpm dev              # docs site: /, /components, /blocks, /themes
pnpm registry:build   # regenerate registry.json, app/ds-tokens.css, public/r (commit the output)
pnpm lint             # oxlint (.oxlintrc.json)
pnpm format           # oxfmt (.oxfmtrc.json); `pnpm format:check` in CI
```

Before pushing: `pnpm lint && pnpm format:check && pnpm typecheck && pnpm check:contrast && pnpm registry:build && pnpm build && pnpm audit:ui`.
